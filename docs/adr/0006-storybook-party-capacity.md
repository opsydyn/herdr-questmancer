# Compare larger parties in Storybook

The owner wants the experience to accommodate more adventurers, including
smaller sprites. The previous station-saturation review establishes the current
problem but does not choose a replacement layout. Continue the established
Storybook-first visual workflow with a bounded comparison before production.

Add eight fixed studies: both rooms with seven full masters, seven small
masters, twenty-four small masters and thirty-two small masters. Reuse authored
16x24 or 8x12 assets, existing production room backdrops and the existing fit
transform/output adapter. Never downsample the 16x24 masters. The provisional
capacity target is 24–32; a target preference was requested and remains optional.
This is not a promise of support for 64 or unbounded parties.

Keep the prototype behind the existing Storybook feature. A new isolated
composition module may place fixture actors over the production backdrop;
production must not import it. Fixed seats follow stable fixture identity rather
than presence, so status changes do not relocate the entire party or alter fit.
State cues retain their literal meanings. Local Tab/Shift-Tab, click selection
and full-size profiles use the existing safe preview controls and profile mask.

These are spatial/density concepts, not a production station policy. The
candidate uses neutral distributed seats and does not claim a seat is an
adventurer's source-owned work station. Decide the preferred spatial grouping
and small-class art quality before promotion. Smaller roster sprites have less
class detail; selected identity and full-size profiles provide detail separately.

No production layout, Herdr facts, agent commands, persistent state, native
transport, dependency or release change is authorized by this experiment. Leave
the retained dogfood party untouched. Keep unsupported native output on the
existing explicitly diagnosed production fallback rather than claiming the
experimental fit is available there.

Test the current crowded-fit failure first, then complete visible bounds,
non-overlap including the Librarian, every mouse target, state-cue pixels,
status-independent seating, keyboard reachability and profile fit/cache behavior.
Run full verification and isolated executable PTY checks. Export source images
for three terminal sizes and retain the exact binary identity. Native appearance
and usability remain human review. The decision may be revisited after that
review; automatic density thresholds and broader campaign grouping are follow-up.

Alternatives: only adding more 16x24 station slots does not address larger
parties; shrinking existing masters discards approved pixels; an expanded room
or campaign navigation may suit much larger parties but needs a separate
interaction/composition decision. Existing small authored masters provide the
least expensive credible test of the user's size proposal.
