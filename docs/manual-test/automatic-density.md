# Automatic party size tiers

Use the retained owned dogfood UI for ordinary review; do not change live agent
facts just to force a density. The fixed Storybook stories are safe larger-party
examples with no Herdr or persistence:

```sh
./target/debug/questmancer-storybook --story world.guild-fit-auto --inspect
./target/debug/questmancer-storybook --story world.delve-fit-auto --inspect
```

1. Review both rooms at ordinary and narrow sizes. The complete fitted room
   should retain full 16x24 masters through eleven visible adventurers and use
   authored 8x12 sprites from twelve onward. Twelve through thirty-two use roomy
   staggered seats; thirty-three through sixty-four use denser seating. The latter
   omits the Librarian actor; `?` still opens the Ledger. Above this fitted-room
   capacity or without usable native graphics, explicit existing fallbacks remain.
2. Inspect the reported seven-person resting/unknown case in both rooms: no
   bottom-packed Hall or single dungeon row. Status changes should update pose
   and cues while seats stay steady. Room furnishings do not assign work.
3. At 32, identify an adventurer needing counsel and an unknown adventurer. Use
   the state glyph and selected identity, then open its full-size profile. Tab/
   Shift-Tab reach every fixture identity; clicking should select the pictured
   actor. Judge small-class recognition separately from the complete-actor tests.
4. Repeat profile open/close and resize with the card open. Room scale must not
   jump; no image may cover the parchment or remain stale after closing. Clicking
   inside it must not select a hidden actor. Keep native class portraits and
   authored fallbacks legible. See also `profile-fit.md`.
5. Watch a real working/completion transition only when separately authorized.
   Full-size masters retain semantic rituals; small masters retain static state
   cues and bounded fresh-spoils effects. Reduced/still scenes require no cleanup
   wake. Fixture/PTY evidence does not establish native animation acceptance.

Computer Use cannot inspect Ghostty. Record actual native readability, opacity,
mouse, resize and animation outcomes separately from automated producer checks.
Keep the remaining synthetic resources open and preserve real agent panes.
