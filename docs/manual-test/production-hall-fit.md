# Proportional production Hall acceptance

Use the retained synthetic party or the guarded procedure in
[scene preview](questmancer-scene-preview.md). Never operate a real or unknown
agent pane. Leave this party open as requested. Computer Use cannot access
Ghostty; the checks below require direct human terminal review. CLI text and
synthetic PTY receipts do not establish visible behavior.

1. Open **Questmancer dogfood**, dismiss any parchment with Esc and press `1`.
   On negotiated Kitty with valid cell pixels, the complete 160x90 Hall should
   fit within the pane, with all current adventurers and the Librarian visible.
   The selected identity/condition and counsel count sit below the room.
2. Resize through roomy, medium and small panes. Room and sprites should keep
   their proportions and pixel edges; letterboxing is expected. At extremely
   small sizes, or when canonical stations cannot fit the party, review the
   existing compact/roster/vignette/status fallback instead. No omitted actor
   should be presented as a complete native Hall.
3. Use `j/k` or Tab to select. The rune and footer should follow selection.
   Click synthetic actors only and check the expected card. Click the Librarian,
   turn a page with `j`, and close with Esc. Clicking letterboxing should not
   select an actor. Selection itself may lazily request output, as before.
4. Inspect cards, `?` Ledger, `/` search, `c` Chronicle, `b` Board and `w` Table.
   The adventurer card keeps the fitted room beneath it; the other modal
   parchments use the existing half-block backdrop while open. Close
   them and confirm the fitted Hall returns without blank rows or ghost images.
   Counsel may be drafted and cancelled for a synthetic agent; never send it.
5. Press `2`: the Delve now uses the same proportional fit when its canonical
   stations fit the party; crowded parties gather over the dungeon before using
   the denser roster composition. Press `1` and
   confirm the fitted Hall returns. Observe working gestures, counsel cues and
   resting poses; record smoothness/flicker independently from protocol success.
6. If font zoom changes proportions, reopen the owned UI pane. Grid resizing
   uses current kernel pixel geometry where available; when the host omits those
   axes, startup negotiation is retained. No concurrent stdin geometry probe or
   removed Herdr graphics endpoint is used.
7. Check there are no stale room images after switching worlds or opening parchment, including
   after close/reopen. Review terminal responsiveness during animation and resize.

Record viewport sizes, cell geometry if known, all actor counts, click outcomes,
image cleanup, animation behavior and any interruption. A pass in one native
terminal is not a pass for every terminal, transport or reconnect case. Do not
claim the synthetic fixtures prove real-agent completion or successful delivery.

The Delve extension is covered by [its focused checklist](production-delve-fit.md).
